# cxt 0.5.1 — more useful query context

This patch improves query selection in the shared CLI/TUI/MCP engine without changing CLI defaults or weakening secret policy.

## What's changed

- Follow bounded two-hop identifier relationships in both directions, carrying related implementations into focused output even when they lack the query's words. Ambiguous names and high-fanout hubs are not treated as resolved references.
- Give strong focused implementations priority over cheap supporting files; prefer explicitly named project-relative modules over generic API chatter. Soft per-file span budgets leave room for multiple implementations; large indivisible units may retry the full budget. Explicit review pins remain first and final rendered-token limits remain mandatory.
- Select named Rust fields with their declaration attributes and original separators instead of requiring the whole struct. Parser cache schema changes invalidate old metadata.
- Preserve original-source secret findings when span preparation fails. `--secrets fail` still checks all prepared candidates, including files later omitted by budgeting.
- Classify evaluation refusals and timing without persisting raw stderr; report actionable preparation/budget failures.

## Install and try

Windows PowerShell:

```powershell
$env:CXT_VERSION='v0.5.1'
irm https://github.com/chinmaykrishnroy/cxt/releases/download/v0.5.1/install.ps1 | iex
```

macOS / Linux:

```bash
curl --proto '=https' --tlsv1.2 -LsSf https://github.com/chinmaykrishnroy/cxt/releases/download/v0.5.1/cxt-installer.sh | CXT_VERSION=v0.5.1 sh
```

Install scripts verify matching release checksums. Raw Windows executables do not change PATH; DMGs contain a CLI binary. Assets are available only after the release workflow publishes them. The package is `cxt-ai`; the command is `cxt`.

```bash
cxt --version
cxt --query "volume changes affect multiple clients" --context adaptive --model cl100k --budget 8000 --manifest --stdout
cxt src/cli.rs --symbol Args::query --context focused --stdout
cxt --tui
```

Bare `cxt` still packs the current directory to clipboard. Use `--output`, `--stdout` or `--ci` for automation.

## Evidence and limitations

See [0.5.1 verification](https://github.com/chinmaykrishnroy/cxt/blob/v0.5.1/docs/QUERY_0_5_1.md) for test boundaries, reproducible measurements, retained failures and provisional public-task comparisons.

Query remains experimental, local lexical/static retrieval, not semantic search or compiler-resolved references. Synthetic recall and provisional source-span labels do not establish downstream coding-agent success or superiority over other tools. Strict secret policy may refuse an entire request because of a finding in a candidate that would not survive the budget; this policy is deliberately unchanged. Secret detection remains best effort.
