# cxt 0.5.0 — reviewable context for developers and agents

This release adds task-aware source representations, exact named-tokenizer budgets, validated parser/dependency caches, a scoped read-only MCP server and portable agent skills to the shared CLI/TUI engine.

## What's new

- Complete files, structural maps, focused original AST implementations and adaptive fallback; named/qualified symbol selection.
- Explainable local BM25, path, symbol and approximate reference signals, with ranking ablations and reproducible evaluation reports.
- Offline cl100k/o200k accounting on the final rendered packet. Other profiles estimate; no billing guarantee.
- Persistent hash-validated parser metadata and static edges with resolver-input invalidation. No cached source bodies.
- Seven MCP tools for one canonical workspace, fixed redaction and bounded requests; no arbitrary commands, output files or persistent cache writes.
- Seven-view TUI with Symbols and editable representation/ranker/scanner/scope controls, plus **E** to export the agent skill.
- Portable `SKILL.md` export for Codex, Claude Code, Antigravity, Devin, Kiro or a custom path, without overwriting existing guides or modifying agent configuration.
- Conservative source compaction, stronger serialization/secret checks, optional Gitleaks integration and expanded resolver regressions.

## Install and use

Windows PowerShell:

```powershell
$env:CXT_VERSION='v0.5.0'
irm https://github.com/chinmaykrishnroy/cxt/releases/download/v0.5.0/install.ps1 | iex
```

macOS / Linux:

```bash
curl --proto '=https' --tlsv1.2 -LsSf https://github.com/chinmaykrishnroy/cxt/releases/download/v0.5.0/cxt-installer.sh | CXT_VERSION=v0.5.0 sh
```

Installers verify the matching checksum manifest. Raw Windows executables do not update PATH by themselves; DMGs contain a CLI binary. Linux `.deb` installation is system-wide; scripts support per-user locations. Assets and checksums are attached after all build targets succeed.

```bash
cxt --version
cxt --query "request retry policy" --context focused --model cl100k --budget 8000 --manifest --output context.md
cxt --tui
cxt --export-skill --skill-agent codex
cxt --export-skill "guides/cxt/SKILL.md"
```

The package remains `cxt-ai`; the executable remains `cxt`. Bare `cxt` still packs the current directory to clipboard. Use `--stdout` / `--output` / `--ci` for automation. The skill is embedded in the binary; `cxt-SKILL.md` is also attached for inspection/import.

## Scope and evidence

Task-aware retrieval is **experimental**, even though this is a final numbered release. Static symbol/import/reference heuristics can miss relevant code; maps are not implementations. Synthetic recall is not proof of AI coding-task success, and exploratory public labels are provisional. Real-task miss rates, safety refusals and latency remain documented areas for improvement. Secret scanning is best effort, not a universal security guarantee.
